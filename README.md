# EIT Tactile Sensing Robotics Research

Using sensor materials and scalable prototype designs to advance research on intelligent, dynamic robots by leveraging EIT data to detect and counteract slip, or otherwise detect and manipulate held objects. Done using feedback on electrical circuitry on a flexible finray gripper (UR5 used for actuation).

This GitHub contains the code for some movement tests done early in research, but unfortunately, since the research is ongoing and will be made into a paper soon, I'm unable to share a majority of the code.

After publication, images and more details will be added.
